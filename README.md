# 프리스타일 라이트 0.4.0-rc.1

Samsung TizenBrew용 리모컨 브라우저와 즐겨찾기, HLS 호환 재생 모듈입니다. 독립 웹 엔진이나 삼성 스토어/WGT 앱은 아닙니다.

홈은 기기 내부 127.0.0.1:18769에서 제공합니다. PC 없이 실행하는 구조이며 외부 사이트·공식 Portal/HLS CDN에는 인터넷 연결이 필요합니다.

## 사용

TizenBrew의 Add GitHub Module에 이 저장소의 소유자/저장소 이름을 입력합니다. 홈의 주소 저장으로 즐겨찾기를 추가합니다. 방향키/확인으로 홈을 조작하고 외부 페이지에서는 초록 버튼으로 커서 모드를 전환합니다. 지원 대상 영상 페이지에서는 오른쪽 위 ‘호환 재생’을 누릅니다. 뒤로 버튼은 호환 화면을 닫거나 홈으로 돌아갑니다.

즐겨찾기는 기기 내 브라우저 저장소에 보관합니다. 저장소를 지우면 즐겨찾기도 지워집니다. 이전 LAN 시험 앱의 즐겨찾기는 origin이 달라 자동 이전되지 않습니다.

## 소스와 재빌드

module.js는 페이지마다 주입되는 읽을 수 있는 JavaScript입니다. index.html, app.css, app.js, site-tools.js, site-player.js는 홈 소스입니다. service-template.js는 기기 내 정적 파일 서비스입니다. Node.js 18 이상에서 아래 명령으로 정적 자산을 service.js에 다시 묶습니다.

```sh
node build-service.mjs
```

HLS.js 1.7.3 파일의 SHA256을 확인한 뒤 빌드합니다. 외부 Portal 런타임은 고정 커밋과 SHA384 무결성 검사로 로드합니다. 라이선스는 THIRD_PARTY_NOTICES.md와 HLS_LICENSE.txt를 참고하세요. TizenTube 코드는 포함하지 않았습니다. 자체 코드에는 별도 재사용 라이선스를 부여하지 않았습니다.

## 확인 범위

이 설치 후보는 PC의 실제 브라우저에서 홈 저장/유지, 중립 HLS 8초 완주, 새 창 차단과 뒤로 복귀를 확인했습니다. 앞선 LAN 시험판은 Freestyle 1세대에서 호환 재생·소리·연속 재생·10초 이동을 확인했습니다. 이 설치 후보의 기기 서비스 시작과 최초 페이지 주입은 실기 확인이 남아 있습니다. 모든 사이트의 속도 개선·광고 차단을 보장하지 않습니다.

개인 즐겨찾기·영상·접속 기록·원격 인증값은 이 저장소에 포함하지 않습니다. 서비스는 루프백에만 바인딩하고 원격 진단이나 주소 수집 기능을 제공하지 않습니다.
